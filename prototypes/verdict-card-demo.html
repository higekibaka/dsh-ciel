分组折叠的实现方案

设置卡片可以按「描述符表 + 递归渲染」实现任意层级的分组折叠。每组一个 group 描述符，children 里再放字段或下一级 group。

function renderField(def, depth) {
  if (def.kind === 'group') {
    const open = !closed[def.key]
    return h('div', { onClick: toggle },
      h('span', null, def.label),
      open ? def.children.map(c => renderField(c, depth + 1)) : null)
  }
  // …route / effort / number / check
}

可访问性已经处理好：组头按钮加了 aria-expanded，键盘用户可以直接操作，屏幕阅读器也能正确播报分组状态。

折叠状态下组头会显示摘要，由描述符的 summarize 函数生成：

  • 顾问组显示 provider / model · 档位
  • 参数组显示 tokens · 次/轮
  • 批评者组显示完整路由

全部 12 个字段的脏检查、保存、校验都改为遍历描述符表，测试已经覆盖，可以放心合并。
